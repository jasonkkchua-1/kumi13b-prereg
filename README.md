# kumi13b — Pre-registration (Kumi Station Protocol)

This repository holds the **pre-registration freeze** for kumi13b, an experiment testing whether frontier language models can learn a novel symbolic grammar in-context and use it compositionally on never-seen material — designed so that known shortcut strategies provably fail.

It was created **private** on 2026-07-23 to timestamp the freeze before any experimental API call, and made public afterwards with its timestamps intact (commitment-before-data, verifiable in the issue history). Issue #1 is the freeze: the certified claim, design summary, locked predictions, amendment history, and the SHA-256 manifest of the (private) experiment code. Results, the independent audit, and prediction grading are posted as follow-up comments on the same issue.

**Part of the Kumi Station Protocol** — a pre-registration discipline for one-shot language-model experiments: pre-register → run once → append-only hash-chained provenance → independent audit → stop for review. Main public record: [kumi-station-protocol](https://github.com/jasonkkchua-1/kumi-station-protocol).
